O que é Iteração?

Iteração é repetir um bloco de código várias vezes.

  • Automatiza tarefas repetitivas
  • Processa listas e dados
  • Evita copiar e colar
  • Torna programas mais eficientes
Exemplo
for i in range(5):
     print(i)
PYTHON Slide 2 / 8

O Loop FOR

Use o FOR quando souber quantas vezes deseja repetir algo.

for i in range(1, 6):
     print(i)

A função range()

range(5)

range(1, 10)

range(0, 20, 2)

A função range() cria sequências numéricas usadas no FOR.

O Loop WHILE

Use o WHILE quando a repetição depender de uma condição.

contador = 1

while contador <= 5:
     print(contador)
     contador += 1
